# i18n Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add multi-language support to Downlodr using i18next, with English as the default, a language picker in Settings, and an incremental migration path for hardcoded strings.

**Architecture:** Locale JSON files live in `src/locales/<lang>/<namespace>.json` and are imported directly (no HTTP backend). i18next is initialized once in `src/core-app/i18n.ts` and imported as a side-effect in `renderer.tsx`. The persisted language preference lives in `settingsStore` and is synced to i18next via a `useEffect` in `App.tsx`.

**Tech Stack:** `i18next@26.0.6`, `react-i18next@17.0.4`, Zustand (existing), React + TypeScript (existing)

> **Note:** This project has no test commands configured. Skip any TDD steps — implementation only.

> **Note (git):** Do NOT run any git commit or push commands. The project owner handles all commits manually.

## Task 2: Create i18n initialization file

**Files:**
- Create: `src/core-app/i18n.ts`

- [ ] **Step 1: Create `src/core-app/i18n.ts`**

```ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';

import enCommon from '@/locales/en/common.json';
import enSettings from '@/locales/en/settings.json';
import enDownlodr from '@/locales/en/downlodr.json';
import enSkedulosa from '@/locales/en/skedulosa.json';
import enPlugins from '@/locales/en/plugins.json';

i18n.use(initReactI18next).init({
  resources: {
    en: {
      common: enCommon,
      settings: enSettings,
      downlodr: enDownlodr,
      skedulosa: enSkedulosa,
      plugins: enPlugins,
    },
  },
  lng: 'en',
  fallbackLng: 'en',
  ns: ['common', 'settings', 'downlodr', 'skedulosa', 'plugins'],
  defaultNS: 'common',
  interpolation: {
    escapeValue: false,
  },
});

export default i18n;
```

- [ ] **Step 2: Add language sync effect to `src/App.tsx`**

In `App.tsx`, i18n must be imported and synced with the persisted language setting after the store rehydrates. Add these imports at the top of the file (alongside existing imports):

```ts
import i18n from '@/core-app/i18n';
```

Then, inside the `App` component function, after the existing `useSettingStore` call (which is already present at the top of the file), add this effect:

```ts
const language = useSettingStore((state) => state.settings.language);

useEffect(() => {
  if (language && i18n.language !== language) {
    i18n.changeLanguage(language);
  }
}, [language]);
```

Place this block after the existing `useSettingStore` destructuring, before the `return` statement.

## Adding a new language later (reference)

When you're ready to add, e.g., Spanish:

1. Copy `src/locales/en/` → `src/locales/es/`
2. Translate all values in each JSON file (keys stay the same)
3. In `src/core-app/i18n.ts`, import the Spanish files and add them under `resources.es`
4. In `SettingsModal.tsx`, add `{ label: 'Español', value: 'es' }` to `languageOptions`

No other code changes needed — `i18n.changeLanguage('es')` handles the rest.
