Prerequisites

Before publishing your Electron app to the Microsoft Store, ensure you have all the necessary accounts, tools, and permissions in place.

Why Publish to Microsoft Store?

🔄
Automatic Updates
Microsoft handles all updates automatically. Users get new versions without manual downloads or prompts.
🔐
Free Code Signing
Microsoft signs your app for free. No need to purchase expensive code signing certificates ($200-500/year).
🛡️
SmartScreen Trust
Store apps bypass Windows Defender SmartScreen warnings. No more "Unknown Publisher" scary dialogs.
🌍
Global Discoverability
Reach 1.4+ billion Windows devices. Users can find and install your app directly from the Store.
📦
Clean Install/Uninstall
MSIX provides sandboxed installation. Apps uninstall cleanly with no leftover files or registry entries.
🏢
Enterprise Ready
IT admins can deploy Store apps via Intune/SCCM. Easier enterprise adoption for B2B SaaS.

What is Intune/SCCM?

Microsoft Intune and SCCM (System Center Configuration Manager) are enterprise tools that IT administrators use to manage thousands of employee computers from a central dashboard.

Without Store (Traditional .exe): IT must download your installer, create custom deployment scripts, test compatibility, and manually push updates to employees. Result: Many companies skip your app.

With Store (MSIX): IT searches "Downlodr" in Intune, clicks "Assign" to deploy to 10,000 employees. Done. Updates happen automatically. Result: One-click enterprise deployment.
Factor Without Store (.exe) With Store (MSIX)
Deployment time Days/weeks 5 minutes
Update management Manual scripts Automatic
Security approval Requires IT review Already signed by Microsoft
IT willingness Hesitant Easy approval
💼
B2B Opportunity: If you ever sell team/enterprise licenses for Downlodr, being on the Store makes adoption dramatically easier. IT departments trust Store apps because they're Microsoft-signed and integrate with management tools.

What is D-U-N-S?

D-U-N-S Number Explained
D-U-N-S (Data Universal Numbering System) is a unique 9-digit identifier for businesses, created by Dun & Bradstreet (D&B). Think of it like a Social Security Number, but for companies.

Microsoft uses D-U-N-S to verify your business is legitimate when you register a Company account. This prevents fraud and builds trust in the Store ecosystem.

How to Get a D-U-N-S Number

Method Cost Time Notes
D&B Direct (Free) $0 30+ days dnb.com - slowest option
D&B Expedited ~$229 1-5 days Pay for faster processing
Apple's Portal Recommended $0 1-14 days developer.apple.com/enroll/duns-lookup
💡
Already have one? Check at dnb.com before applying. Many registered businesses already have a D-U-N-S number assigned.

MSIX Packaging

MSIX is Microsoft's modern Windows app packaging format, introduced in 2018 as the successor to MSI/EXE installers.

What is MSIX?

MSIX is a containerized app format that combines the best features of MSI, AppX, and App-V. Apps are packaged into a single file that Windows understands natively, enabling:
  • Sandboxed installation (apps don't scatter files across your system)
  • 100% clean uninstalls (no leftover registry entries or files)
  • Differential updates (only download what changed)
  • Built-in digital signatures for security

MSIX vs Traditional Installers

Aspect EXE / MSI / NSIS MSIX Modern
Installation Scatters files across C:\Program Files, AppData, Registry Contained in isolated app folder
Uninstall Often leaves leftover files and registry keys 100% clean removal guaranteed
Updates Full package re-download every time Differential (only changed blocks)
Security Full system access during install Sandboxed with declared capabilities
Store Compatible ❌ No ✅ Yes
Enterprise Deployment Requires custom scripts Native Intune/SCCM support
💡
File extensions: MSIX packages use .msix or .appx extensions. Both are functionally the same for the Microsoft Store.

Setup Electron Forge for MSIX

Install the MSIX maker
npm install --save-dev @electron-forge/maker-appx
Add to forge.config.ts
import { MakerAppX } from '@electron-forge/maker-appx'; // In your makers array: new MakerAppX({ publisher: 'CN=YOUR_PUBLISHER_ID', publisherDisplayName: 'Your Company Name', identityName: 'YourCompany.YourApp', assets: './build/appx', }),
⚠️
The publisher value must exactly match your Partner Center identity, including CN= prefix.

Build & Sign

Generate your MSIX package. Microsoft signs it when you upload.

Build command
npm run make -- --platform=win32
Output location
out/make/appx/x64/YourApp-1.0.0.appx
  • Verify MSIX file created
    Check out/make/appx/ for .appx or .msix file.
  • Test install locally (optional)
    Requires developer mode for unsigned packages.
✅
You don't need to sign the package yourself. Microsoft handles signing during submission.

⚠️ Video Downloader Apps & Store Policy

Can Downlodr be published to Microsoft Store?
✅ YES - Video downloaders ARE on the Microsoft Store.

Multiple apps like "Video Downloader Standard", "UTube Downloader", and others are currently live and regularly updated. However, there are important considerations:

Key Risks & Considerations

⚖️
Copyright & ToS Concerns
YouTube's Terms of Service prohibit downloading. Your app could face DMCA requests from content platforms. Position your app for legitimate use cases (personal backups, offline viewing of owned content).
📝
Required Disclaimer
Include a clear disclaimer stating users are responsible for complying with copyright laws and third-party terms of service. This is how existing apps pass certification.
🔄
Ongoing Maintenance
YouTube frequently changes its API/structure to break downloaders. Your app needs constant updates to remain functional. This is expected behavior for this category.

Best Practices for Positioning Downlodr

  • Focus on "Media Library" features
    Emphasize organization, playback, and format conversion over downloading.
  • Add prominent disclaimer in-app
    "Users are responsible for ensuring downloaded content complies with applicable laws and third-party terms of service."
  • Include Privacy Policy URL
    Required for Store submission. Host on your website.
  • Avoid mentioning specific platforms in Store listing
    Don't say "Download from YouTube" - say "Download videos from supported websites".
💡
Pro tip: Position Downlodr as a "Media Manager with download capabilities" rather than a "YouTube Downloader". This framing is safer for Store approval and more accurate to your vision.

Common Rejection Reasons

Missing Privacy Policy
Required if app collects user data or uses analytics.
Crashes or Errors
App must work without crashes. Test thoroughly.
Inaccurate Description
Listing must accurately describe functionality.
Publisher Identity Mismatch
Package publisher must match Partner Center.
